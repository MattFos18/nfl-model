How every number on a card is made
Model points
Each team's expected points from the fitted equation: a base for a league-average team in a neutral game, plus each rating's distance from the league average times what it is worth, plus the situation (home, rest, roof, wind, cold, division, primetime). "Why these numbers" on any card lists every input; Model → How it was built prints the whole equation.
Model spread and total
Home expected points minus away, and the two added together.
Vegas points
What the line implies: (total ± spread) ÷ 2.
Edge
Model line minus the Vegas line, in points, with the side it favours. The flag fires at : the thresholds that won in both backtest windows (History tab), on small samples.
Win %
Model: the chance the final margin lands above zero when the margin is treated as a bell curve centred on the model spread with a 13-point spread (the actual miss over 2013 to 2025), reshaped so 3 and 7 get their true share. Vegas: the moneyline with the bookmaker's cut removed, so the two sides sum to 100%.
Cover %
The same bell curve: the chance the margin beats the Vegas spread. Vegas's own number is 50% by construction, so the model's cover % is the whole disagreement.
Over %
The chance the total lands above the Vegas total, bell curve centred on the model total, 13.4-point spread.
Break-even
52.4% at −110. A cover or over % below that is a losing bet even if the model is right on average.
